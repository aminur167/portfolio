# Developer Portfolio

Personal developer portfolio website showcasing projects, technical skills, and professional background.

## Features

- Hero section with introduction
- Project cards with descriptions and links
- Skills section with technology badges
- Responsive navigation
- Contact section
- Mobile-first responsive design

## Project Structure

```
index.html        - Main page structure
style/
  portfolio.css   - Complete styling
images/           - Portfolio assets
```
